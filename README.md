## Deploy with Cloudflare Pages

### Option A — GitHub-connected deployment (recommended)
1. Create a new public GitHub repository, for example `balaji-portfolio`.
2. Upload the contents of this folder to the repository root (make sure `index.html` is at the root).
3. In Cloudflare Dashboard, open **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
4. Select the `balaji-portfolio` repository.
5. Framework preset: **None**.
6. Build command: leave blank.
7. Build output directory: `/` (or `.` if Cloudflare requests a relative directory).
8. Click **Save and Deploy**.

### Option B — Direct upload
1. Open Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages**.
2. Choose the direct upload option.
3. Upload this project's folder or a ZIP of its contents.
4. Deploy. Cloudflare will provide a `*.pages.dev` address.

## Update the site
Edit `index.html`, `styles.css` or `script.js`, then commit and push to GitHub. With Git integration, Cloudflare Pages automatically redeploys after each push.
