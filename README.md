# Balaji Ravi — Career-focused Portfolio

A static portfolio for Cloudflare Pages, retaining the existing root-level deployment structure and supplied portrait/social preview assets.

## Included
- `index.html`, `styles.css`, `script.js` — responsive portfolio with larger typography, accessible navigation, project filters and targeted resume downloads.
- `assets/Balaji_Ravi_Resume.pdf` — master resume for general networking.
- `assets/Balaji_Ravi_Resume_RWE_Healthcare.pdf` — targeted RWE / healthcare analytics resume.
- `assets/Balaji_Ravi_Resume_Data_Product_Analytics.pdf` — targeted data / product analytics resume.
- `assets/Balaji_Ravi_Resume_AI_ML.pdf` — targeted junior AI / ML resume.
- `assets/Balaji_Ravi_Resume_Master.pdf` — duplicate master-format download for explicit naming.
- Existing portrait, social preview, favicon, web manifest, sitemap and robots file.

## Resume integrity
The resume versions are based on the supplied portfolio source and its existing resume. No unverified performance metrics, employment claims, certifications, visa status or project outcomes have been invented. Project descriptions are presented as portfolio work, not professional employment. Review contact details, dates, technical skills and each project repository before submitting applications.

## Deployment
The site is a static website. For the existing Cloudflare Pages project, retain the current repository and branch configuration, root directory `/`, and no build command. Back up the existing local folder and preserve `.git` when copying these files into the working repository. Deploy only after reviewing the updated site locally.


## Resume
The portfolio contains one official, ATS-friendly resume at `assets/Balaji_Ravi_Resume.pdf`. It combines the supplied professional experience, education, skills and selected projects into one consistent profile.
